# Sonsuz Özür Dileyen Makine

Bu proje, insanlığın en büyük sorununu çözmek için tasarlanmıştır: **Yeterince özür dilememek.**

## Ne Yapar?

`python ozur_makinesi.py` komutunu çalıştırdığınızda, script rastgele, abartılı ve tamamen gereksiz özürler üretir. Özür diledikten sonra özür dilediği için de özür diler. Sonsuza kadar devam edebilir (Ctrl+C ile kurtulabilirsiniz, ama o zaman da özür dilersiniz).

## Özellikler

- Tamamen Türkçe özürler
- Rastgele nedenler: nefes almak, var olmak, klavye kullanmak vs.
- Abartılı ciddiyet
- Hiçbir şey için pratik değildir
- %100 çalışan kod (gerçekten)

## Kurulum

Python 3 yükleyin. Başka hiçbir şeye ihtiyacınız yok. Özür dilerim kurulumun bu kadar basit olması için.

## Kullanım

```bash
python ozur_makinesi.py
```

## Uyarı

Bu programı çalıştırmak sizi daha iyi bir insan yapmaz. Ama en azından özür dilediğiniz için daha az kötü hissedersiniz. Belki de etmezsiniz. Özür dilerim.

## Katkıda Bulunma

Pull request açın, ama önce özür dileyin. Lütfen.
